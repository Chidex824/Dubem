Build notes

  • Design widths are 390, 768 and 1200. The layout reflows on the width of the site area, using container queries.
  • Start the public pages from the ThemeWagon JobEntry template: its job list, job detail and application form layouts map to Home, Job detail and Post an opportunity.
  • Sign up, Account and Admin have no matching template page. Build them from the components on this page, and keep the Django admin for moderation until the custom queue is ready.
  • Use one Bootstrap version only, or drop it and use these tokens as CSS variables.
  • Every control needs a visible focus state and a label. Status never relies on colour alone, so pills carry text.

  • NavBar, SearchHero, FilterSidebar, JobRow, VerifiedBadge
  • SaveButton, AlertRow, AlertForm, FrequencyToggle
  • SignUpForm, VerifyEmailCard, Banner
